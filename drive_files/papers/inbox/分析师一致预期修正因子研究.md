# 分析师一致预期修正因子研究

## 摘要

本文研究分析师对上市公司盈利预测的一致预期修正行为对股票未来收益的预测能力。我们认为，分析师集体上调盈利预测的股票，其基本面预期改善，未来收益倾向于更高；反之，分析师集体下调盈利预测的股票，未来收益倾向于更低。基于此构建分析师一致预期修正因子（AnalystRevision）。

## 因子构建

### 核心变量

**一致预期EPS（ConsensusEPS）**：市场上所有覆盖该股票的分析师对下一个财年每股收益预测值的算术平均。该数据来自分析师一致预期数据库，包含每家上市公司的：

- **一致预期EPS**：全部分析师预测的均值
- **一致预期EPS一个月前值**：一个月前的一致预期EPS
- **分析师覆盖数**：覆盖该股票的活跃分析师数量

### 因子定义

**分析师一致预期修正（AnalystEpsRevision）**：

```
Revision_t = (ConsensusEPS_t - ConsensusEPS_{t-1M}) / |ConsensusEPS_{t-1M}|
```

其中：
- `ConsensusEPS_t`：第 t 日一致预期EPS
- `ConsensusEPS_{t-1M}`：一个月前（约20个交易日）的一致预期EPS
- 分母取绝对值，保证修正幅度的方向正确

**含义**：Revision > 0 表示分析师集体上调盈利预测（基本面改善信号）；Revision < 0 表示集体下调（基本面恶化信号）。

### 使用数据

该因子需要以下数据字段（均来自分析师一致预期数据库）：

1. `consensus_eps`：一致预期EPS（当前值）
2. `consensus_eps_prior`：一致预期EPS（一个月前）
3. `analyst_coverage`：分析师覆盖数

### 计算流程

1. 对每只股票，取当日一致预期EPS与一个月前一致预期EPS
2. 计算修正幅度 = (当前 - 一个月前) / |一个月前|
3. 每只股票每日输出一个原始值

## 结论

分析师一致预期修正因子捕捉的是卖方分析师盈利预期的变化方向与幅度，属于基本面预期类因子。该因子与传统的动量因子、价值因子相关性较低，可作为多因子模型的补充维度。
